# تطبيق TS-GSM (Android)

تطبيق يغلّف منصة **ts-gsm.dz** داخل تطبيق أندرويد احترافي، ويمنح إذن الكاميرا
تلقائيًا لخاصية الحضور (QR / باركود) — دون رسائل حظر من المتصفّح.

## المزايا
- يفتح المنصة بملء الشاشة باسم وأيقونة التطبيق (شعارك).
- **إذن الكاميرا تلقائي** لمسح QR/الباركود في قسم الحضور.
- رفع الصور والملفات (صور الطلاب، الوثائق).
- تنزيل الملفات (Excel / PDF / النسخ الاحتياطية) عبر مدير التنزيل.
- يفتح روابط واتساب/الهاتف/البريد في تطبيقاتها.
- يحفظ جلسة الدخول («تذكّرني» 24 ساعة يعمل بين الجلسات).
- زرّ الرجوع يتنقّل داخل صفحات المنصة.

---

## الطريقة 1 — بناء سحابي مجاني (لا يحتاج أي برنامج) ✅ المُوصى بها

1. أنشئ حسابًا على **GitHub.com** (مجاني).
2. أنشئ مستودعًا (Repository) جديدًا، وارفع إليه مجلّد `android-app` ومجلّد `.github`
   (يمكن السحب والإفلات من زر **Add file → Upload files**).
3. افتح تبويب **Actions** في المستودع ← اختر **Build TS-GSM APK** ← **Run workflow**.
4. انتظر ~3–5 دقائق حتى تكتمل (علامة ✓ خضراء).
5. افتح عملية البناء ← في الأسفل قسم **Artifacts** ← نزّل **TS-GSM-apk**.
6. فُكّ الضغط ← ستجد `app-debug.apk` ← انقله للهاتف وثبّته
   (فعّل «تثبيت من مصادر غير معروفة» عند الطلب).

> كل مرة تعدّل فيها شيئًا وترفعه، يبني GitHub نسخة APK جديدة تلقائيًا.

---

## الطريقة 2 — عبر Android Studio (إن كان مثبّتًا)

1. افتح **Android Studio** ← Open ← اختر مجلّد `android-app`.
2. انتظر مزامنة Gradle.
3. **Build ← Build Bundle(s) / APK(s) ← Build APK(s)**.
4. ستجد الملف في `app/build/outputs/apk/debug/app-debug.apk`.

---

## تغيير الرابط أو الاسم أو الأيقونة
- **الرابط:** `app/src/main/java/dz/tsgsm/school/MainActivity.java` ← ثابت `START_URL`.
- **الاسم:** `app/src/main/res/values/strings.xml` ← `app_name`.
- **الأيقونة:** استبدل `app/src/main/res/drawable-nodpi/ic_logo.png` بشعارك (مربّع).
- **لون خلفية الأيقونة:** `app/src/main/res/values/colors.xml` ← `ic_launcher_background`.

## ملاحظة عن النشر على Google Play
النسخة الناتجة هي **debug** (مناسبة للتثبيت المباشر والتوزيع الداخلي).
للنشر على متجر Play يلزم توقيع نسخة **release** بمفتاح خاص — أخبرني وأضيف خطوات التوقيع.
